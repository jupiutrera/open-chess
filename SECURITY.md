# Security policy

Open Chess runs on your own device and has no server of its own. The optional Supabase sync talks to an instance you host yourself.

## Reporting a vulnerability

Please don't open a public issue. Use GitHub's [private vulnerability reporting](https://github.com/jupiutrera/open-chess/security/advisories/new) instead, with the steps to reproduce it and the version affected.

Only the latest release gets fixes.
