# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep criticism about the code and not the person, and no harassment of any kind. Maintainers may remove comments, commits or issues that break this, and block people who keep doing it.

Report problems privately to the maintainer through their GitHub profile.
